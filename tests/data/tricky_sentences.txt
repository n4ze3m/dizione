# Tricky sentences for the phonemizer (front end "own").
#
# TEXT   what the user types
# SAID   the words the normaliser must turn it into. Punctuation marks stand
#        alone; [A M] is read letter by letter; +word continues the word before
#        it (no word boundary); {...} is a pronunciation given inline.
# PHONES optional: a stretch of the token sequence that must appear, phones
#        separated by spaces, stress marked ˈ ˌ, <sp> between words.
#
# tests/test_phonemizer.py checks every block. Add a block for every bug fixed.
